# 📱 App & Play Store Studio Pro

A high-performance, web-based Screenshot & Mockup Generator for **Apple App Store** and **Google Play Store**, built with React, Vite, and HTML5 Canvas.

## ✨ Features

- 🍎 **Apple App Store Support**:
  - iPhone 6.7" Display (`1284x2778`)
  - iPhone 6.5" Display (`1242x2688`)
  - iPad Pro 12.9" (`2048x2732`)
- 🤖 **Google Play Store Support**:
  - Android Phone 20:9 Flagship (`1080x2400`)
  - Android Phone 16:9 Standard (`1080x1920`)
  - 7" Android Tablet (`1200x1920`)
  - 10" Android Tablet (`1600x2560`)
  - Android Foldable Display (`2176x1812`)
  - Google Play Feature Graphic Banner (`1024x500`)
- 🎨 **Realistic Device Chassis & Finishes**:
  - Titanium Dark, Phantom Black, Titanium Silver, Ceramic White, Midnight Navy, Emerald Forest, and Custom frame tinting.
  - Configurable Android Punch-Hole camera (Centered, Left, Right, Pill, or Hidden).
  - Subtle specular glass reflections and realistic drop shadows.
- 🔄 **Portrait & Landscape**: Seamless 1-click rotation and angle adjustment (`-180°` to `+180°`).
- 🌟 **Instant Layout Presets**: Hero Centered, Bottom Peek, Slanted 3D, Full Fill, and Feature Graphic banner layouts.
- 🎨 **Advanced Backgrounds**: Solid colors, curated store gradients (Google Modern, Android Cyber, Deep Indigo, etc.), and custom image upload with blur & dark overlay.
- 🔤 **Arabic & English Fonts**: Preloaded with Cairo, Tajawal, Almarai, Readex Pro, Outfit, Inter, Montserrat, Poppins, Playfair Display, and Bebas Neue.
- 📁 **Custom Font Upload**: Drag and drop your own `.ttf`, `.otf`, `.woff`, or `.woff2` brand fonts.
- ⚡ **Native 1:1 Pixel Export**: Crystal clear, high-resolution PNG exports matching Apple App Store and Google Play Store submission requirements.

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/WesamNabeel/app-store-studio-pro.git

# Navigate to directory
cd app-store-studio-pro

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

# 📱 AppStore Studio Pro

A high-performance, web-based App Store Screenshot Generator for iPhone and iPad built with React, Vite, and HTML5 Canvas.

![AppStore Studio Pro](src/assets/hero.png)

## ✨ Features

- 📱 **iPhone & iPad Modes**: Native resolutions for iPhone 6.7" (`1284x2778`) and iPad Pro 12.9" (`2048x2732`).
- 🔄 **Portrait & Landscape**: Switch mockup orientation with 1 click.
- 📐 **360° Tilt & Rotation**: Custom rotation angle sliders & quick preset tags (`+15°`, `-15°`, `45°`, `90°`).
- 🌟 **Instant Layout Presets**: Hero Centered, Bottom Peek, Slanted 3D, and Full Fill layouts.
- 🎨 **Advanced Backgrounds**: Solid Hex colors, curated palette swatches, dual-color gradients with angle control, and background image crop/zoom/blur.
- 🔤 **Arabic & English Fonts**: Includes Cairo, Tajawal, Almarai, Readex Pro, Outfit, Inter, Montserrat, Poppins, Playfair Display, and Bebas Neue.
- 📁 **Custom Font File Upload**: Drag and drop your own `.ttf`, `.otf`, or `.woff` brand font files.
- ⚡ **Native 1:1 Pixel Export**: Crystal clear, un-distorted PNG exports matching Apple App Store requirements.

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/WesamNabeel/app-store-studio-pro.git

# Navigate to directory
cd app-store-studio-pro

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
